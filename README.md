# Alapozás – nyitóoldal

A tárgy nyitóoldala: bevezetés (talaj és szerkezet kölcsönhatása, az alapozás feladata, alaptípusok, határállapotok, interaktív feladatok),
a tárgy útja kilenc állomásban (görgetésre felépülő, ráközelítő metszettel), gyűjtőoldal az összes tananyaghoz, a félév menete, bevezető animáció.

- Egyfájlos `index.html` (a CSS és a JS beágyazva), mellette `fonts/`, `img/`, `vendor/hyphenopoly/`, `video/bevezeto.html`, `video/bevezeto-en.html`, `video/elozetes.mp4` (a hős kártyájának néma előzetese).
- Forrás: `_src/` (index.src.html, style.css, app.js) → `cd _src && python3 build.py` → `../index.html` (és `../artifact.html` az előnézethez).
- A tananyagok adatai (címek, URL-ek, leírások, jelvények) az `_src/app.js` elején, az `S` tömbben vannak; a félév órarendje a `W` tömbben (2026-os dátumokkal).
- Formázás: sorkizárás + magyar elválasztás (Hyphenopoly hu.wasm), nem törő egységek őre, keskeny dobozban lyuk esetén balra zárt tartalék.
- A bevezető videó forrása: `Claude videók/_forras/bevezeto_forras.zip` (a kit a `hatasok_forras.zip`-ben van).
- Átfogó tananyagok almappákban: `telek/` (Egy telek, egy félév – esettanulmány 3D-makettel), `helyszinelok/` (Geotechnikai helyszínelők – kárügyek), `tippelj/`, `vizsga/` és `ar-labor/` (Alapozás AR labor). Mindegyik önálló, kész oldal. Az AR labor modelljeinek forrása itt van: `_src/ar/` (three.js-ből épülő, animált modellek: `models/*.js`, közös segédek: `lib/common.js`; `cd _src/ar && npm install && node build.mjs [id…] [--models|--poster] [--labels] [--t=…]` → `ar-labor/models/<fájl>{,-feliratok,-feliratok-en}.glb/.usdz`, poszter: `_src/ar/out/`; a CFA-modell korábbi, kész fájl). Az oldal magyar forrása az `ar-labor/index.html`, az angol a `python3 _src/build_sub.py` kimenete.
- **Angol változat (/en):** a nyitóoldalé az `_src/i18n_en.py` párjaival készül (`python3 build.py` → `../en.html`). Négy extra – `helyszinelok/` (Geotechnical CSI), `tippelj/` (Guess, then calculate), `vizsga/` (Exam simulator), `telek/` (One site, one semester) – angolul is elérhető (`<app>/en.html` → `/<app>/en`): `cd _src && python3 build_sub.py` (előfeltétel: `cd _src/sub_i18n && npm install`). A fordítások: `_src/sub_i18n/en_*.tsv` (azonosító = a magyar szöveg sha1-ének első 7 jegye); ha a magyar szöveg változik, a build leáll, a hiányzók: `_src/sub_i18n/missing.tsv`. A magyar `index.html`-ekben benne van a HU | EN nyelvváltó, az `EN` jelző és az angol tördelési szabályok; ha valamelyiket külső forrásból újragenerálják, `python3 sub_prep_hu.py` visszateszi ezeket.
- **AR labor (`ar-labor/`, 2026-11-22 óta saját generátorból, mindkét nyelven):** `python3 _src/ar-labor/build.py` → `ar-labor/index.html`, `en.html`, `qr.html` (nyomtatható QR-lap), `xr.js`. A sablon (`_src/ar-labor/page.tpl.html`) az Építőmérnök bemutató AR Laborjából való (`MBalika/geotechnika-bemutato`), az előadásokhoz igazítva; minden szöveg és modelladat a `build.py`-ban van. A saját modellek forrása: `_src/ar/models/` – `cd _src/ar && npm install && EN=1 node build.mjs <id…>` (`--poster`: indexkép-alap az `_src/ar/out/` mappába); négy modell (MOL Campus, M4-metró, rázóasztal, mobilgát) fájljai a kari repóból valók. A CFA-modell angol feliratos változata: `cd _src/arlab_en && python3 build.py`.
